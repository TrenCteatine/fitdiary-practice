# Реестр исправлений

## B01 — булева версия JSON

Найдено при проверке формата: Python считает `True == 1`, поэтому проверка `schema != 1` пропускала `schema: true`. Фактическое воспроизведение до исправления сохранено в `bug_before.txt`.

Исправлено: `type(data['schema']) is int` и проверка значения 1. Регрессионный тест `test_boolean_schema_rejected` завершился успешно. Ошибка затрагивала валидацию формата, а не расчет КБЖУ.

## B02 — нижние элементы интерфейса при масштабировании

Найдено на работающем Windows exe: начальная высота Treeview в 10 строк увеличивала запрошенную высоту экрана, из-за чего кнопка удаления и строка состояния не помещались в окно.

Исправлено: исходная высота таблиц 5 строк, при этом свободная область продолжает расширяться. Пересобран exe и визуально проверены четыре вкладки. В `screenshots/nutrition.png` видны кнопка удаления и строка состояния. Автоматические проверки после исправления прошли.

## Контроль расчета отладчиком

`debug_session.txt` содержит реальную сессию pdb: точка останова перед вычислением, просмотр стека и `entry`, одиночный шаг и проверка `totals`. Получено `(250.0, 25.0, 12.5, 50.0)` для порции 250 г. Проверка не выдается за работу в конкретной IDE.
