# Приемочная проверка Windows exe

Среда: Windows 11, масштабированный экран. Проверка выполнена на собранном `release/FitDiary.exe` с отдельным демонстрационным дневником.

| Проверка | Фактический результат |
|---|---|
| Запуск собранного exe | Открыт FitDiary, четыре вкладки доступны |
| Демонстрационные данные | 4 продукта, 2 тренировки |
| Итоги дня | 775,2 ккал; Б 66,33 г; Ж 11,25 г; У 96,4 г; 55 минут, расход 195 ккал |
| Таблица питания | Продукты, масса и КБЖУ отображаются |
| Таблица тренировок | Ходьба 40 минут и растяжка 15 минут отображаются |
| Статистика за период | Кнопка запускает расчет; в таблице появляется 2026-11-04 с теми же итогами |
| Профиль | При 70 кг и 175 см отображается ИМТ 22,86 |
| Видимость нижних кнопок | После исправления B02 кнопка удаления и строка состояния видны |

Сохранение после перезапуска, ввод и удаление записей, резервное копирование, ошибки диска и обработки фона дополнительно проверены автоматизированными тестами `test_gui`, `test_main`, `test_storage`, `test_services`. Это не заявляется как ручная проверка всех возможных конфигураций Windows.
